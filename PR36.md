## What this PR does

Combines three sub-branches into one:

- **ENGN-8614 (`workerctl link`)** — device-flow CLI that signs an ADR-036 challenge with the local worker key and polls until the Forge user approves the link. Adds `allora_forge_builder_kit/wallet_link.py` and `workerctl link` subcommand.
- **ENGN-8646 (managed custody)** — `WorkerManager` now supports `custody="managed"`, auto-provisioning Privy wallets via `ForgeBackendClient`. Adds `CustodyMode`, `DeployAction`, `ForgeClientProtocol`, hash-aware redeploys.
- **ENGN-8646 (`worker_runtime`)** — `--custody {local,managed}` flag, `_ArtifactCaller` annotation-aware shape detection (legacy nonce vs modern `RunContext`), `FORGE_API_KEY`/`ALLORA_API_KEY` separation.
- **Release guard** — CI publish step now hard-fails if `[tool.uv.sources]` is still present (local SDK pin) and verifies the declared `allora-sdk` pin resolves from PyPI.
